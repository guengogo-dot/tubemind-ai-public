# TubeMind AI

TubeMind AI is a Chrome extension for working with YouTube transcripts without losing your place in the video.

## What it does

- Search inside available YouTube transcripts.
- Jump from a transcript segment to the matching video timestamp.
- Copy transcript text and useful moments for notes or research.
- Create optional AI summaries with a user-configured compatible AI provider.
- Keep transcript navigation beside the YouTube video in Chrome.

Transcript features depend on captions being available for the selected YouTube video.
